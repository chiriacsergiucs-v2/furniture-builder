# Nonfunctional requirements

- **NFR-001** [CONFIRMED] No backend, accounts, remote sync or runtime cloud APIs — `MOD-012`
- **NFR-002** [CONFIRMED] Use exact integer millimetre inputs and stable geometric constraints — `MOD-002`
- **NFR-003** [CONFIRMED] Never claim globally optimal packing — `MOD-002`
- **NFR-004** [CONFIRMED] Fail closed when a cutting result violates validator invariants — `MOD-003`
- **NFR-005** [CONFIRMED] Legacy data must never be deleted during migration — `MOD-006`
- **NFR-006** [CONFIRMED] Migration must be atomic and idempotent — `MOD-006`
- **NFR-007** [CONFIRMED] Backward-compatible JSON backups across schema changes — `MOD-006`
- **NFR-008** [CONFIRMED] Static PWA must preserve core use offline — `MOD-012`
- **NFR-009** [CONFIRMED] Viewer must degrade gracefully without WebGL — `MOD-008`
- **NFR-010** [CONFIRMED] Preserve touch and keyboard access for reorder controls — `MOD-008`
- **NFR-011** [CONFIRMED] Avoid release claims without executed CI and deploy evidence — `MOD-012`
- **NFR-012** [CONFIRMED] Do not fabricate joinery, fitting, drilling or structural certifications — `MOD-011`
- **NFR-013** [CONFIRMED] New templates must reuse typed component rules rather than duplicating engines — `MOD-010`
