# ADR-0008: Kerf is a full-length destroyed stripe; residuals narrower than kerf are rejected

## Context

A guillotine cut removes a stripe of material equal to the blade kerf along the whole cut. Many hobby optimisers
model kerf as a gap only between adjacent parts, which under-counts waste and can emit a layout where the last
part does not physically fit.

## Decision

Each `cut` node in the cut tree carries `kerf`; the second child starts at `at + kerf`. A part fits a free
rectangle only when `available === required` **or** `available - required >= kerf` (`canSeparate`). Residuals
that are positive but smaller than kerf are conservatively rejected rather than silently absorbed. Kerf area is
counted explicitly in statistics and in the validator's conservation equation.

## Alternatives considered

- **Kerf as inter-part gap only** — rejected: under-counts material removed on edge cuts and can produce unfittable layouts.
- **Allow sub-kerf residual (treat as dust)** — rejected: a residual that cannot be separated is not a valid saw operation; the user prefers an honest "does not fit" to a layout that fails on the saw.

## Consequences

- Utilisation figures are slightly more pessimistic than competing tools; this is intentional.
- The validator re-checks every `cut` node: `kerf` equals `project.settings.kerf`, and `at` lies inside the parent rectangle with non-negative remainder.
- Changing kerf semantics requires updating `guillotine.ts`, `validate.ts` and `docs/algorithm.md` together.

## Evidence (repository files)

- `src/engine/guillotine.ts` — comments "Kerf is material destroyed by each full-length separating saw pass. A residual narrower than kerf is conservatively rejected (never silently ignored)"; `canSeparate`, `fitRect`, `insertIntoWaste`.
- `src/engine/validate.ts` — `if(kerf!==project.settings.kerf) issues.push('Kerf mismatch')`; vertical/horizontal cut checks.
- `docs/algorithm.md` — "Cuts consume full-length kerf stripes; a residual too narrow for the configured kerf is rejected."
- `tests/engine.node.test.mjs` — kernel tests.

## Compliance check

`npm run test:kernel` passes; a fixture with free width = part width + (kerf − 1) is rejected by `fitRect`.
