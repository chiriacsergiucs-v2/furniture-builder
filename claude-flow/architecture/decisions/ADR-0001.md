## Context

The product is a cutting optimiser for a small furniture workshop. Users work on phones and laptops, often
offline in a workshop. The repository ships as a Vite single-page app with a PWA service worker and is published
by a GitHub Actions workflow to `https://chiriacsergiucs-v2.github.io/furniture-builder/`.

## Decision

The application is a **static, offline-capable PWA** built with React 19 / TypeScript / Vite 7 and
`vite-plugin-pwa`, served from GitHub Pages at base path `/furniture-builder/`. Routing is hash-based so deep
links survive static hosting. The service worker uses `registerType: 'prompt'`; releases are picked up through the
in-app *Update app* prompt, never by clearing site data.

## Alternatives considered

- **Server-rendered app with a backend** — rejected: violates the no-backend constraint (ADR-0002) and adds
  hosting cost and an attack surface for a single-workshop tool.
- **Native mobile app** — rejected: duplicate code paths for desktop/mobile; PWA install covers the Android use case.
- **Path-based routing** — rejected: GitHub Pages cannot rewrite unknown paths to `index.html`; hash routing is the
  reliable static option (`navigateFallback` is still configured for the SW).

## Consequences

- Every feature must work with no network after first load; assets are precached (`globPatterns` for js/css/html/svg/png/woff2, 8 MB cache cap per file).
- Base path `/furniture-builder/` must be kept in sync across `vite.config.ts`, the PWA `scope`/`start_url` and any absolute links. Older documents that mention another repository or base path are stale (see `evidence/conflicts.md`).
- A deployment claim requires the `Deploy GitHub Pages` workflow run to succeed; the live site is not independently HTTP-checked by CI.

## Evidence (repository files)

- `vite.config.ts` — `base: '/furniture-builder/'`, `VitePWA({registerType:'prompt', manifest.scope/start_url, workbox...})`.
- `.github/workflows/deploy.yml` — build + `actions/deploy-pages@v4` on push to `main`.
- `docs/deployment.md` — published URL, update-prompt guidance.
- `AGENTS.md` §"Current architectural requirements" — "Static GitHub Pages PWA".

## Compliance check

`grep -n "base:" vite.config.ts` returns `/furniture-builder/`; `npm run build` succeeds; no `fetch(` to a non-same-origin URL exists in `src/` (`grep -rn "https\?://" src/ --include=*.ts --include=*.tsx` only returns comments/doc links).
