## Context

Research feature *Live price/cost estimate* (rank 24, value 4.1 "Medium if data exists", P1/P2; Roomle pricing,
Cyncly live pricing data, VividWorks). The app has no prices anywhere. ADR-0002 forbids remote services and ADR-0010
forbids invented data, so prices can only come from the user. Supplier price feeds or online ordering would be a
non-free outside integration: that part is split into **ADR-0060 (Pending)**.

## Decision

- **Price list on this device:** the next free Dexie version adds table `prices: 'id'` (shared with ADR-0057's
  `projectTemplates` if built in the same change; otherwise whichever ships second takes the following version). Entries:
  - board: by `materialKey` (name + thickness + grain), price **per sheet** (stock sheet size from the board) or
    **per m²** — the user chooses which;
  - edge banding: per metre, by board;
  - hardware: per item kind as the hardware schedule names it (hinge, runner pair, handle, rail …);
  - run parts use their board's price; worktop boards may be priced per piece.
- **Estimate:** project and piece *Parts* tab show **"Estimate: 4 812 lei — 3 prices missing"**: sheets from the
  nesting result (ADR-0018) × sheet price, or m² × m² price; edge-band metres × price; hardware counts × price.
  Missing prices are listed by name, never guessed; the total is marked *incomplete* while any is missing.
- **Currency:** one setting, default **lei (RON)** (the app's outputs are Romanian); amounts are user input, shown
  with two decimals; no exchange rates.
- **Import/export** of the price list as CSV (`kind;key;unit;price`), like the decor list (ADR-0049).

## Alternatives considered

- **Prices stored on each board in the design** — every copy of a piece would carry its own price and drift.
- **Supplier price feed** — needs a remote, usually paid, service: ADR-0060 (Pending).

## Consequences

- Estimates are only as good as the user's list; the UI says "your prices, saved on this device".

- Unit tests: estimate from sheets and from m²; missing prices listed, total marked incomplete; CSV round trip;
  unreadable price rows skipped and kept.
- Find-it at 1440 and 375 px: piece → **Parts** → **Prices** → enter a sheet price for the body board → the line
  **Estimate:** shows a total and **prices missing** for the rest.
- `npm run lint && npm run typecheck && npm test && npm run build`.

## Questions and answers (2026-10-24; recommended answers auto-accepted on the user's instruction)

1. *Where do prices come from?* — **The user's own list on this device; supplier feeds are ADR-0060 (Pending).**
2. *Board price per sheet or per m²?* — **User's choice per board; sheet counts from nesting when per sheet.**
3. *Currency?* — **One setting, default lei (RON); no conversion.**
4. *What if a price is missing?* — **Listed by name; total marked incomplete; nothing guessed.**
