## Context

The original build prompt (`CUTLIST_OPTIMIZER_RESUMABLE_BUILD_PROMPT_v2.md`) forbids remote services. The user
runs a private workshop and does not want customer cutlists, dimensions or workbooks to leave the device, nor any
paid dependency. This constraint predates and is independent of the storage decision in ADR-0003.

## Decision

The application has **no server component**: no remote database, no user accounts, no cloud synchronisation, no
customer-data uploads, no remote AI/LLM calls and no runtime dependency on a third-party HTTP API. All computation
(optimisation, validation, 3D, exports) runs in the browser. Dexie Cloud and similar paid sync add-ons are
explicitly excluded.

## Alternatives considered

- **Optional cloud backup** — rejected for now: would require accounts/consent handling and conflicts with the
  explicit no-cloud instruction. May be revisited only by a new explicit user decision (authority order in `memory/decision-guardrails.json`).
- **Server-side optimiser for larger jobs** — rejected: the heuristic engine completes within `maxDurationMs` in a Web Worker (ADR-0013); workshop job sizes do not justify a service.

## Consequences

- Data portability relies entirely on local JSON backups (ADR-0006); loss of site data is loss of data unless exported.
- Dependency additions must be checked for network side-effects before adoption (`delivery/dependencies.md`).
- Any agent proposal that introduces a network call, token, key or SaaS SDK is a **change-control** event (`workflows/change-control.md`), not an implementation detail.

## Evidence (repository files)

- `AGENTS.md` — "No remote database, backend, cloud sync, accounts, paid service, customer data uploads, remote AI APIs, or runtime external API dependency."
- `docs/architecture.md` — "No server, database, auth or external runtime API. Browser exports stay local."
- `docs/licences.md` — "No Dexie Cloud or paid sync features are installed."
- `package.json` — dependency list contains no HTTP client, auth or cloud SDK.

## Compliance check

`package.json` dependencies unchanged from the audited list or additions reviewed; `grep -rn "fetch(\|XMLHttpRequest\|WebSocket" src/` returns nothing outside the service worker generated by Workbox.
