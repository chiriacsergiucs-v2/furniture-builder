# ADR-0002: Static offline PWA on GitHub Pages; no backend, accounts, cloud or remote services

| | |
|---|---|
| **Status** | Accepted |
| **Decided** | 2026-10-21 (carried from earlier user constraints) |
| **Supersedes** | — |
| **Related** | ADR-0012, ADR-0013 |
| **Owning role** | release |

## Context

The tool is used in a workshop, often offline, by a single owner who does not want designs leaving the device or
any paid dependency.

## Decision

The app is a static single-page PWA served from GitHub Pages at `/furniture-builder/` (overridable with
`BASE_PATH` for previews). A Workbox service worker precaches all assets; new versions prompt the user ("Update
now") instead of reloading mid-edit. There is no server, account, sync, telemetry, remote AI or runtime third-party
request. Fonts are bundled (`@fontsource`), not loaded from a CDN.

## Alternatives considered

- **Hosted backend with sync** — rejected: violates the no-cloud constraint and adds cost.
- **Native app** — rejected: one PWA covers phone and desktop.

## Consequences

- Durable copies rely on the user exporting design files (ADR-0012).
- Any dependency with network side-effects is a change-control event.

## Evidence (repository files)

- `vite.config.ts` — `base`, `VitePWA({ registerType: 'prompt', workbox.globPatterns })`.
- `src/main.tsx` — `registerSW` with an explicit update bar.
- `package.json` — no HTTP client, analytics or cloud SDK.

## Compliance check

`grep -rn "fetch(\|XMLHttpRequest\|https://" src/` returns nothing; `dist/` contains no external `<script src>`.
