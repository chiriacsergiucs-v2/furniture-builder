# ADR-0010: Hardware is a schedule with labelled guidance, never invented specifications

## Context

Runner, hinge and rail choices depend on the supplier's datasheet. Pretending to know drilling patterns or load
ratings would be dangerous.

## Decision

The model lists hardware lines: runner pairs (longest stocked length that fits, from the user's list), hinges
(count by typical door-height bands, labelled "typical — confirm with the hinge datasheet"), clothes rails (cut to
opening width) and rail supports. Hardware never becomes a panel. Screws, connectors, handles and drilling are not
listed and the UI says so.

## Alternatives considered

- **Full supplier catalogue** — deferred until the user picks suppliers.

## Consequences

- Runner clearance and lengths are user settings with datasheet hints.

## Evidence (repository files)

- `src/core/cabinet.ts` — `hingeCount`, `hingeBand`, runner selection.
- `src/core/cutlist.ts` — `hardwareSummary`.
- `src/ui/Output.tsx` — Hardware tab note.

## Compliance check

No `HardwareItem` produces a `Panel`; hinge notes contain "confirm with the hinge datasheet".
