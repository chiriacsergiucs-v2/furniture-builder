## Context

Research feature *Reusable ensemble templates* (rank 21, value 4.3, P1; pCon, IKEA planners). The paper: save the
ensemble as a template with item references, defaults, relative positions, connections and generated-part recipes.
Single-piece templates exist (Dexie v3 `templates`, ADR-0034); built-in Mobila rooms are shipped projects. A user's
own project cannot be reused as a starting point except by duplicating it in the Library.

## Decision

- **Project → "Save as project template"** stores: name, description, the pieces (embedded design copies, as
  ADR-0032 snapshots), their positions **relative to the leftmost-back piece**, quarter turns, placements, the
  run-part **recipe** (which kinds were suggested and the scribe/plinth settings, ADR-0051) — not the run-part
  geometry, which is suggested again — and the room (ADR-0055/0056) only if the user ticks *Include the room*.
- **Storage:** the next free Dexie version (7 today; ADR-0059's `prices` table takes the version after whichever
  ships first, or both tables share one version if built in the same change) adds
  `projectTemplates: 'id, updatedAt, name'`. Earlier versions are not edited (ADR-0012); unreadable rows are
  skipped, never deleted.
- **Use:** Home → *Create a new project* → **From a project template** list; the Catalog page → *Saved on this device*
  shows project templates in their own group with *Use*, *Rename*, *Delete* (confirmation). Using one creates a new
  project with fresh ids and suggests run parts from the recipe.
- **Export/import:** a project template is exported/imported as a file like designs (`kind: 'project-template'`).

## Alternatives considered

- **Flag rows in the `projects` table** — older app versions would list templates as projects; a separate table
  keeps them apart.
- **References to library pieces instead of copies** — a deleted or edited library piece would silently change or
  break the template; copies match ADR-0032.

## Consequences

- One more Dexie version; an older cached app opening the newer database follows the existing update prompt (F17).
