## Context

The user is iterating on product shape and explicitly does not want agents to spend budget on E2E matrices,
refactors, documentation expansion or polish before the MVP exists.

## Decision

Before writing code an agent asks whether each change is necessary to demonstrate the requested feature **now**.
Default verification is `lint + typecheck + build` plus a focused unit test only where it catches a core-logic
error. No new E2E/browser suites, abstractions, performance work or refactors by default. Legacy tests stay
intact. Pushed branch ≠ merged ≠ deployed ≠ verified live. Every implementation reply ends with a **Skipped this
iteration** section. Scope expands only on explicit user authorisation or when essential for correctness/data safety.

## Alternatives considered

- **Full verification sequence on every change** — retained as the *release* gate (ADR-0029), not the iteration gate.

## Consequences

- Browser acceptance is reported as "unverified" unless Playwright actually ran.
- The task contracts in `tasks/tasks.json` carry a `scope_guard` field mirroring this rule.

## Compliance check

Final reply of an implementation turn contains "Skipped this iteration"; no new file under `src/tests/e2e/` without an explicit user request.
