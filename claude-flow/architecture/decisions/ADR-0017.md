# ADR-0017: Agent contracts stay runtime-neutral until a Claude Flow / Ruflo version is pinned

| | |
|---|---|
| **Status** | Proposed |
| **Decided** | 2026-10-21 |
| **Supersedes** | — |
| **Related** | — |
| **Owning role** | orchestration |

## Context

No orchestration runtime is declared in the repository.

## Decision

`claude-flow/agents`, `workflows` and `tasks/tasks.json` are plain contracts read by agents. Pinning a runtime
(TSK-R01) means recording its version, generating its scaffold in a disposable worktree, translating, and validating
with its CLI; then this ADR becomes Accepted.

## Alternatives considered

- **Guess a runtime schema** — rejected: unverifiable.

## Consequences

- Nothing in the folder claims to be "installed".

## Evidence (repository files)

- `package.json` — no `claude-flow`/`ruflo` dependency.

## Compliance check

`grep -i "ruflo\|claude-flow" package.json` is empty while this ADR is Proposed.
