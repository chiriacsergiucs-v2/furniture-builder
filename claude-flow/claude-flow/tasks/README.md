# Task contracts

Each object in `tasks.json` contains objective, inputs, relevant requirements, dependency IDs, intended modules/files, deliverables, acceptance test descriptions, completion criteria and verifier handoff. These are **neutral contracts**, not verified CLI-native tasks. Begin with READY `TSK-002`, `TSK-011`, `TSK-012`; investigate templates via `TSK-010`; `TSK-001` needs runtime pin. Other statuses are not silently promoted.
